# Use Vesper

Vesper

Open or drop a local file/folder. Space plays/pauses, Left/Right seeks, M mutes, F/F11 toggles
full screen, Esc leaves full screen or cancels an opening request. The subtitle/audio menu selects
tracks and scrolls when long. Drop SRT/ASS/SSA/VTT, or load one there; matching subtitles beside
the movie are considered automatically. Text encoding can be selected explicitly when older
subtitles show wrong characters. Set the preferred subtitle language in the search sheet.

Ctrl+F opens online subtitle search: edit the suggested title and language, choose a provider,
then Search in browser. Download there, unzip if necessary, and load/drop the subtitle. Vesper
does not upload your full path or automatically query/download subtitles. I shows video details;
comma/period steps frames, brackets change speed, Backspace resets it, Z/X adjusts subtitle delay.

F1 lists the app's current shortcuts. Light/dark/follow-Windows themes are in More. Long listening,
A/V sync, real clipboard/media keys, mixed-monitor DPI and physical input remain useful user checks.
